### 编程任务

```
写一个 Python 函数，解析 CSV 文件并按指定列分组求和
```

**DeepSeek-V3 输出：**

```python
import csv
from collections import defaultdict

def group_and_sum(csv_path: str, group_col: str, sum_col: str) -> dict:
    """按指定列分组求和"""
    result = defaultdict(float)
    
    with open(csv_path, 'r', encoding='utf-8') as f:
        reader = csv.DictReader(f)
        for row in reader:
            key = row[group_col]
            value = float(row[sum_col])
            result[key] += value
    
    return dict(result)

# 使用示例
if __name__ == "__main__":
    data = group_and_sum('sales.csv', 'region', 'amount')
    print(data)
```

代码质量：✅ 完整、有类型提示、有文档、有示例

## API 调用

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.deepseek.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "你好"}
    ],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content, end="")
```

## 本地部署

DeepSeek 提供了蒸馏版模型，可以用单卡部署：

```bash
# 使用 vLLM
pip install vllm

python -m vllm.entrypoints.openai.api_server \
    --model deepseek-ai/deepseek-v3 \
    --tensor-parallel-size 4 \
    --port 8000
```
