pgvector 让 PostgreSQL 具备了向量检索能力，可以直接在数据库里做 RAG 检索。

## 安装

```sql
CREATE EXTENSION vector;
```

## 基本使用

### 创建向量列

```sql
-- 创建表
CREATE TABLE documents (
    id SERIAL PRIMARY KEY,
    content TEXT,
    embedding vector(1536)  -- OpenAI embedding 维度
);

-- 创建索引
CREATE INDEX ON documents USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);
```

### 插入数据

```python
import psycopg2
from openai import OpenAI

client = OpenAI()
conn = psycopg2.connect("postgres://user:pass@localhost/db")

def insert_document(content):
    # 生成 embedding
    response = client.embeddings.create(
        model="text-embedding-3-small",
        input=content
    )
    embedding = response.data[0].embedding
    
    # 插入数据库
    cur = conn.cursor()
    cur.execute(
        "INSERT INTO documents (content, embedding) VALUES (%s, %s)",
        (content, embedding)
    )
    conn.commit()
```

### 向量检索

```sql
-- 余弦相似度检索
SELECT content, 1 - (embedding <=> '[0.1, 0.2, ...]'::vector) as similarity
FROM documents
ORDER BY embedding <=> '[0.1, 0.2, ...]'::vector
LIMIT 10;
```

## 索引选择

| 索引类型 | 特点 | 适用场景 |
|---------|------|---------|
| ivfflat | 聚类索引 | 中等数据量（< 100万） |
| hnsw | 图索引 | 大数据量、高召回率 |
| 无索引 | 精确搜索 | 小数据量（< 10万） |

### HNSW 索引

```sql
CREATE INDEX ON documents USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
```

参数说明：
- `m`: 每个节点的连接数，越大越精确但占用更多内存
- `ef_construction`: 构建时的搜索深度

## 混合检索

```sql
-- 向量 + 全文检索
WITH vector_results AS (
    SELECT id, content, 
           1 - (embedding <=> query_vector) as score
    FROM documents
    ORDER BY embedding <=> query_vector
    LIMIT 50
),
text_results AS (
    SELECT id, content,
           ts_rank_cd(to_tsvector(content), query) as score
    FROM documents, to_tsquery('postgresql & vector') query
    ORDER BY score DESC
    LIMIT 50
)
SELECT COALESCE(v.id, t.id) as id,
       COALESCE(v.content, t.content) as content,
       COALESCE(v.score, 0) * 0.7 + COALESCE(t.score, 0) * 0.3 as final_score
FROM vector_results v
FULL OUTER JOIN text_results t ON v.id = t.id
ORDER BY final_score DESC
LIMIT 10;
```

## 性能优化

### 1. 分区表

```sql
CREATE TABLE documents (
    id SERIAL,
    category VARCHAR(50),
    content TEXT,
    embedding vector(1536)
) PARTITION BY LIST (category);
```

### 2. 预热索引

```sql
-- 查询前预热
SELECT pg_prewarm('documents_embedding_idx');
```

### 3. 并行查询

```sql
SET max_parallel_workers_per_gather = 4;
```
