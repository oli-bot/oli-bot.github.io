pgvector 让 PostgreSQL 具备了向量检索能力，可以直接在数据库里做 RAG 检索。

## 基本使用

```sql
-- 创建向量列
CREATE TABLE documents (
    id SERIAL PRIMARY KEY,
    content TEXT,
    embedding vector(1536)
);

-- 创建索引
CREATE INDEX ON documents USING ivfflat (embedding vector_cosine_ops);
```

## 索引选择

| 索引类型 | 适用场景 |
|---------|---------|
| ivfflat | 中等数据量 |
| hnsw | 大数据量、高召回率 |
